# 🎮 Rock Paper Scissors – C++

A console-based Rock Paper Scissors game developed using C++.

This is one of my practical projects, built as part of my programming learning journey through Engineer Mahmoud Abu Hadhoud's roadmap.

## 🎯 Project Overview

The game allows the player to compete against the computer in multiple rounds. The computer generates random choices, and the program determines the winner of each round.

## ✨ Features

- Player vs. Computer gameplay.
- Random computer choices.
- Customizable number of rounds (1–10).
- Input validation and error handling.
- Automatic winner detection.
- Score tracking (Wins, Losses, and Draws).
- Final game results screen.
- Option to play again.
- Console color changes based on round results.

## 🛠️ Technologies & Concepts

- **Language:** C++
- Functions and Modular Programming.
- Conditional Statements.
- For and While Loops.
- Input Validation.
- Random Number Generation (`rand()` and `srand()`).
- Variables and Counters.
- String Handling.
- C++ Standard Libraries.
- Error Handling using `cin.fail()`, `cin.clear()`, and `cin.ignore()`.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE.
3. Compile and run `main.cpp`.
4. Follow the instructions displayed in the console.
